Introduction

We are pleased to announce Version 9.21v — focused on improving ticket management, asset association, checklist usability, dashboard interaction, and user account recovery across the Metaagrow web application.

This release introduces Biometric Login for faster and more secure authentication, Dynamic Search for improved listing navigation, Time-Based Checklists for better task scheduling, and Reports functionality directly within the mobile application.
