Introduction

We are pleased to announce Version 9.21v — focused on improving ticket management, asset association, checklist usability, dashboard interaction, and user account recovery across the Metaagrow web application.

This release introduces enhanced ticket functionality with a new Critical priority option, editable ticket details, increased character limits, flexible asset linking, department assignment, and additional ticket type options.

The update also improves inspection and maintenance checklist usability through question shuffling, enhances dashboard and report date interactions, and introduces Forgot Password functionality for administrators on the web login page.

Operational Workflow Improvements Across Ticketing, Checklist, Dashboard, and Admin Access
  • Add "Critical" priority option in the ticket module for better urgency classification
  • Enable editable ticket details with increased character limits up to 1000 characters
  • Allow asset reassignment from a ticket at any time and assign department values
  • Provide additional ticket type options and direct asset linking from ticket and asset detail views
  • Shuffle checklist questions in inspection and maintenance creation/editing workflows
  • Make dashboard and report date sections clickable and fully functional, and support admin forgot-password recovery on the web login page
